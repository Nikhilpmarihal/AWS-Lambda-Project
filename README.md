# AWS Lambda Project

This repository contains the code for an AWS Lambda based project.

## Files

- `contactus.html`: The HTML contact form interface.
- `lambda_function.py`: The Python source code for the AWS Lambda function.
- `success.html`: The success page displayed after form submission.

## Setup

1.  Deploy the `lambda_function.py` to AWS Lambda.
2.  Configure the `contactus.html` to point to the deployed API Gateway endpoint (if applicable).
